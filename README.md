# Brightroot Dental — concept website

Concept website for a fictional family dental clinic. Designed and built by **[The Cybrix](https://thecybrix.in)** as a portfolio piece.

**Live demo:** https://brightroot-dental-demo.netlify.app

> Brightroot Dental is a fictional business. All names, prices and details are sample content.

## Features

- Interactive appointment slot picker (choose a day, then an available time)
- Upfront treatment price list
- Step-by-step "what happens at your visit" section
- Accessible FAQ built with native details/summary
- Opening hours table and simple illustrated map

## Built with

- Hand-written HTML, CSS and vanilla JavaScript — no frameworks or build step
- Mobile-first, responsive layout tested from 390px phones to wide desktops
- Accessibility: semantic headings, skip link, visible keyboard focus, labelled form fields, `prefers-reduced-motion` support
- Self-hosted fonts embedded in the page, so it works offline and loads with no third-party requests

## Run locally

Open `index.html` in any browser. That's it.
